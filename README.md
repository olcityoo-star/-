# Внутри — умный холодильник на своей Wi‑Fi камере

Домашняя система по принципу «умного холодильника»: камера делает снимок полок, программа узнаёт продукты и показывает их в приложении на телефоне.

Коммерческие холодильники Samsung Family Hub / LG InstaView используют несколько камер, датчик двери и свои модели. Здесь тот же принцип, но на любой IP-камере и компьютере в домашней сети.

## Что получится

- Список продуктов на полках, сгруппированный по категориям
- Скан по кнопке: кадр с камеры, с загруженного фото или демо
- История «появилось / пропало» и список покупок
- PWA: сайт открывается с телефона как приложение

Распознавание можно включить в четырёх режимах:

| Режим | Когда выбирать |
| --- | --- |
| `demo` | Проверка приложения без камеры и нейросети |
| `ollama` | Бесплатно и локально: Ollama + модель `llava` на домашнем ПК |
| `openai` | Самое точное чтение упаковок, нужен API-ключ |
| `yolo` | Локальный YOLO-World, без облака, хуже читает этикетки |

## Железо

1. **Камера.** Подойдёт любая с RTSP или HTTP-снимком: TP-Link Tapo, EZVIZ, Imou, «китайские» IP-камеры, некоторые Xiaomi после включения локального потока. Камеры, которые отдают картинку *только* через облако производителя, для этой схемы неудобны.
2. **Компьютер.** Ноутбук, мини-ПК или Raspberry Pi 4 (для Ollama/YOLO лучше машина с видеокартой или хотя бы 8 ГБ RAM).
3. **Питание камеры.** Тонкий USB-кабель вдоль уплотнителя двери или аккумуляторная камера. Толстый кабель портит уплотнитель и морозит компрессор чаще.
4. **Где крепить.** Металлический шкаф глушит Wi‑Fi. Не ставьте камеру вглубь корпуса. Надёжные варианты: магнит на *внутренней стороне двери*, край полки у проёма, или камера с антенной снаружи и объективом внутрь.

Снимайте при **открытой двери**: лампочка холодильника даёт свет, на линзе меньше конденсата. Закрытый тёмный шкаф камера «не видит».

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app
```

Откройте http://127.0.0.1:8080 с компьютера или `http://<ip-компьютера>:8080` с телефона в той же Wi‑Fi сети. Нажмите **Скан** — без камеры откроется демо-холодильник.

### Подключить камеру

В приложении камеры найдите локальный поток. Типичные адреса:

- Tapo: `rtsp://<логин>:<пароль>@192.168.x.x:554/stream1`
- EZVIZ / многие IPC: `rtsp://admin:<пароль>@192.168.x.x:554/h264/ch1/main/av_stream`
- HTTP-снимок: `http://192.168.x.x/snapshot.jpg` или `/cgi-bin/snapshot.cgi`

Пропишите URL в разделе «Камера и ИИ» или в `.env` как `CAMERA_URL`.

### Распознавание по-настоящему

**Ollama (рекомендуется дома):**

```bash
# на компьютере с Ollama
ollama pull llava
```

В настройках приложения: детектор `ollama`, URL `http://127.0.0.1:11434`. Если сервер крутится на другом ПК — укажите его адрес.

**OpenAI Vision:** детектор `openai`, ключ `OPENAI_API_KEY`, модель `gpt-4o-mini`.

**YOLO-World:**

```bash
pip install -r requirements-ml.txt
```

Детектор `yolo`. Хорошо находит бутылки, овощи, яйца; плохо читает «просто белый стаканчик».

```bash
cp .env.example .env

```

## Ограничения

Одна камера не видит то, что стоит сзади или в ящике. Упаковки без этикетки к камере путаются. Это нормально: даже заводские системы ошибаются, поэтому в приложении можно добавить продукт вручную. Если нужен почти полный учёт — поставьте вторую камеру на другую полку или сканируйте, чуть отодвинув передний ряд.

Не кладите камеру на еду и не используйте блок питания, который греется внутри шкафа.
