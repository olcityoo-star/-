# Умный холодильник

Веб‑сервер средней версии: камера **GoPlus CamPro / ActionCam_f8160c0282c2**, снимок полок, распознавание YOLO и список продуктов в браузере.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn fridge.main:app --host 0.0.0.0 --port 8000
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Камера

ActionCam поднимает свою Wi‑Fi сеть (`ActionCam_f8160c0282c2`, пароль по инструкции часто `12345678`). Телефон в приложении GoPlus CamPro подключается именно к ней, а не к домашнему роутеру.

Чтобы сервер видел камеру:

1. Включите Wi‑Fi на камере.
2. Подключите компьютер или Raspberry Pi к SSID `ActionCam_f8160c0282c2`.
3. В интерфейсе оставьте хост `192.168.25.1` и поток:

   `http://192.168.25.1:8080/?action=stream`

Пока устройство сидит в сети камеры, интернета обычно нет — это нормально для режима точки доступа. Позже можно поставить Raspberry Pi с двумя адаптерами: один в камеру, второй в домашний Wi‑Fi.

Пока камера не подключена, можно **загрузить фото** полок и пройти тот же сценарий: распознать → поправить подписи → добавить на полки.

## Распознавание

Кнопка «Скачать YOLO» загружает `yolov5n.onnx` (COCO). Модель хорошо видит бутылки, фрукты, овощи, миски. Молоко, сыр и одинаковые упаковки нужно будет дообучить позже — сейчас их можно подписать вручную на кадре.
